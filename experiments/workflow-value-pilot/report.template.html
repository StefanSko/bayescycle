What do these checks establish—and what don’t they?

Interval ≠ MCSE

The 95% interval describes posterior uncertainty about β. MCSE measures numerical uncertainty in the estimated posterior mean. They answer different questions.

Good sampling ≠ truth

R̂ and ESS help detect sampling problems. They don’t establish that the model is scientifically appropriate, or that a particular interval must contain the true parameter.

Agreement ≠ equivalence proof

The predeclared mean-difference screen is 4 × √(MCSE²A + MCSE²B). It is a conservative pilot check, not a formal equivalence test.

03 / What it took to get there

The friction was
around the fit.

The initial NumPyro session needed fewer steps. That is one observed run—not a universal productivity ranking or a measure of inference speed.

Include sessions
A

No initial repair

NumPyro’s existing prediction API handled the forward simulation. The initial task finished with no flagged tool error.

What went wrong later?

The revision agent supplied a non-unique text-edit match, then corrected it. A harness editing error, not a NumPyro failure.

B

One export-code repair

The agent assumed a native diagnostic object was a dataclass. Export failed after recovery sampling; it fixed its code and reran with the same seed.

Was the bad attempt hidden?

No. It preserved the attempt. Repeated recovery draws were identical. The agent also wrote a conditional predictive calculation because the public simulation API exposes prior prediction, not a generic posterior-predictive helper.

C

More boundary work

Prior simulation rejected observed y in design inputs. Diagnose and predictive dry plans selected the other engine. The agent added explicit Python helpers instead.

What did the CLI still provide?

Native IR, canonical inputs and fingerprints; successful pinned uvx export and trace plotting. The first export/plot command took about 32 seconds. No silent Rust-backend fallback occurred.

Read these numbers cautiously. Shared caches, concurrent load, different NUTS implementations and agent familiarity are confounds. Error flags also miss shell failures whose exit status was masked; the written incident records above give the fuller story.
04 / The continuity test

Could someone new
pick it up?

Each handoff used a fresh agent with no earlier conversation. It had to identify the current model and reconstruct the answer from saved files, without fitting again.

CheckA · NumPyroB · BayesjaxC · CLI
All setups used files. A and B wrote their own manifests; C brought native artifact contracts. Passing handoff did not require a bespoke workflow platform on this fixture.

What changed in revision

One prior, not the scientific question:

β ∼ Normal(0, 1.00 0.25)

Each agent retained the original model, prior checks, recovery and fit. It wrote separate revised artifacts and marked the earlier model-dependent results as superseded—not deleted.

What provenance could tell us

  • Do the saved files match their recorded hashes?
  • Which prior and dataset belong to the current result?
  • For C, do native draws and model/data fingerprints match?

Local consistency is not an authenticated execution history. We did not test hostile tampering or exact replay after moving the study.

06 / What to take from it

Evidence to simplify.
Not a reason to scrap it.

One small, synthetic, prescribed-model task cannot settle the value of an entire project. It can make the next experiment more focused.

Observed

The core works.

Your library and workflow produced consistent estimates, preserved history and supported handoff. Existing tools achieved those outcomes too.

Interpretation

Extra layers need a job.

The CLI added standardized provenance but not a unique success in this test. A concrete gap was prediction ergonomics—not a missing orchestration platform.

Still open

Can you drive it?

The next useful test is a real study where you question assumptions, inspect evidence and decide what happens next. That was the original product goal.

Not compared

Tau, PydanticAI, MCP, the Rust engine, and the full gated study skill. Pi was held fixed. A small Python-native harness integration is a plausible next prototype, not a conclusion of this experiment.
