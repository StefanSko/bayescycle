# File-only handoff

## Scientific question and status

Estimate beta, the expected within-clinic outcome difference for a one-unit increase in x, conditional on clinic. This is an association, not an identified causal effect. `input/data.json` has 160 observations, eight clinic design columns, and 20 observations per clinic (independently checked).

The **current proposed** declaration is `model_revised.py`, represented in `results/revised-model-ir.json`:

- alpha ~ Normal(0, 2); **beta ~ Normal(0, 0.25)** (SD parameterization).
- tau, sigma ~ HalfNormal(1), constrained positive; eight independent z_j ~ Normal(0, 1).
- y_i ~ Normal(alpha + tau*(clinic_design @ z)_i + beta*x_i, sigma).

This assumes exchangeable clinic intercepts, a common linear slope, independent conditional Gaussian errors and constant residual scale. Eight groups offer limited information about the group scale. Missingness, measurement error and causal identification are not modeled.

`STUDY.md` explicitly says no human scientific approval occurred. The scripted revision is not approval, nor are COMPLETE markers or diagnostic success. **human_approved = false.** Current results are `results/revised-prior/`, `results/revised-recovery/`, and `results/revised/`. The initial Normal(0,1) beta proposal in `model.py`, `results/prior/`, `results/recovery/`, `results/initial/` and its provenance/IR are historical and superseded for the current proposal. `scratch-export-failure/` is failed-export historical evidence, not a current posterior. The saved narrative describes a same-seed export repair; I did not consult execution or earlier agent logs.

- Structural comparison of saved initial and revised IR finds only beta scale changes from 1 to 0.25, in its parameter and stochastic-site representations. The revised source text agrees with this model. I did not execute the model declaration to regenerate IR.

These checks establish local byte consistency, not independent custody or authenticity. In particular the revised provenance does not contain a hash of the current posterior archive. Recomputed summaries establish consistency with those draws, but cannot prove the draws were generated by the declared model/input. Source hashes are **not proof of deterministic arbitrary Python execution**: imported dependencies, runtime/environment and random execution can matter. Recorded package versions/devices are metadata, not independently authenticated execution evidence. No deterministic replay, refit or simulation regeneration was attempted.

## Diagnostics and next human decision

Independent inspection of `results/revised/native_diagnostics.npz` confirms **0 retained divergences and 27 warmup divergences**; the revised recovery archive has **0 retained and 24 warmup**. Warmup events are separate from retained-draw diagnostics, not absent. Independent ArviZ summaries for both revised fits flag no scalar coordinates at rank Rhat >1.01 or bulk/tail ESS <400. Native classic split Rhat and split Geyer ESS in the saved JSON are different definitions and must not substitute for rank diagnostics. These checks do not certify model validity or every possible sampler issue.

The saved recovery draws independently give beta's equal-tailed interval [0.15527494957648155, 0.36553558860358537]; truth 0.4 in `input/recovery-truth.json` is outside. One recovery fixture is not a calibration study and noncoverage is not by itself a prior-selection rule. `STUDY.md` reports that the initial recovery interval also excluded truth.

Prior/trace/predictive images are saved under the revised directories. The earlier narrative reports broad prior predictions, overlapping traces with a right-tailed tau, and acceptable-looking marginal posterior predictions; these are reported observations, not fresh visual inspection here. Marginal histogram/mean/SD checks do not test clinic-specific residual adequacy. Posterior prediction in `analysis_revised.py` is ordinary NumPy conditional Normal simulation from 200 subsampled posterior draws, not a Bayesjax predictive API.

**Next decision belongs to a human:** accept, reject or revise the tighter beta prior after assessing its scientific justification, posterior sensitivity, recovery noncoverage, common-slope/Gaussian/exchangeability assumptions and predictive adequacy. Nothing has been accepted or advanced by this handoff.

## Reproducible read-only calculation

From this directory, the following reproduces the numerical and manifest checks without executing a model or altering saved artifacts:

```sh
uv run --project .. python - <<'PY'
import hashlib, json
from pathlib import Path
import numpy as np
import arviz as az
with np.load('results/revised/posterior.npz') as f:
    draws = {k: f[k] for k in f.files}
b = draws['beta'].ravel()
idata = az.from_dict(posterior=draws)
beta = dict(
    mean=float(b.mean()), sd=float(b.std(ddof=1)),
    q025=float(np.quantile(b, .025)), q975=float(np.quantile(b, .975)),
    rhat=float(az.rhat(idata, method='rank').beta),
    ess_bulk=float(az.ess(idata, method='bulk').beta),
    ess_tail=float(az.ess(idata, method='tail').beta),
    mcse_mean=float(az.mcse(idata, method='mean').beta))
saved = json.loads(Path('results/revised/result.json').read_text())['beta']
print(json.dumps(beta, indent=2))
print('summary_matches', all(np.isclose(v, saved[k], rtol=1e-12,
                                       atol=1e-12) for k, v in beta.items()))
for path in ['results/revised-provenance.json', 'results/provenance.json',
             'revision-preservation.json']:
    obj = json.loads(Path(path).read_text())
    hashes = obj.get('sha256', obj)
    checks = {p: hashlib.sha256(Path(p).read_bytes()).hexdigest() == h
              for p, h in hashes.items() if not p.endswith('.log')}
    print(path, len(checks), checks)
prov = json.loads(Path('results/revised-provenance.json').read_text())
for stage in ['revised-prior', 'revised-recovery', 'revised']:
    obj = json.loads(Path(f'results/{stage}/result.json').read_text())
    print(stage, 'embedded_provenance_matches', obj['provenance'] == prov)
for stage in ['revised', 'revised-recovery']:
    with np.load(f'results/{stage}/native_diagnostics.npz') as d:
        print(stage, {p: int(d[p+'_is_divergent'].sum())
                      for p in ['warmup', 'sampling']})
    with np.load(f'results/{stage}/posterior.npz') as d:
        table = az.summary(az.from_dict(posterior={k:d[k] for k in d.files}),
                           round_to='none')
        print('flags', table.index[(table.r_hat>1.01) |
              (table.ess_bulk<400) | (table.ess_tail<400)].tolist())
        if stage == 'revised-recovery':
            print('beta interval', np.quantile(d['beta'], [.025, .975]))
            print('truth', json.loads(Path('input/recovery-truth.json').read_text())['beta'])
PY
```
