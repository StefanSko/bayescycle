Mixed-backend workflows are explicit

Bayescycle now separates backend intent from backend-native data files. A workflow plan is resolved before any run directory is created, and stages exchange canonical bayescycle.data.json.v1 artifacts.

Default: one backend for every stage

uv run bayescycle workflow-plan --backend bayesite --engine /path/to/bayesite

Result: simulate and recover both use Bayesite.

{
  "mode": "single",
  "stages": {"simulate": "bayesite", "recover": "bayesite"},
  "backends": {"bayesite": {"engine": "/path/to/bayesite"}}
}

If --backend is omitted, Bayescycle resolves the same single-backend plan using the configured/default backend rather than choosing independent per-stage defaults.

Explicit mixed plan with TOML

[workflow]
mode = "mixed"

[stages.simulate]
backend = "bayesite"

[stages.recover]
backend = "jaxstanv5"

[backends.bayesite]
engine = "/Users/me/Projects/bayesite/target/release/bayesite"
uv run bayescycle workflow-plan --config workflow.toml

Result: the plan is mixed only because every stage backend is assigned explicitly.

Canonical artifact handoff

The Bayesite simulation stage writes a canonical simulated data artifact:

uv run bayescycle simulate model.py \
  --data inputs.json \
  --truth truth.json \
  -o run-sim/ \
  --backend bayesite \
  --engine /Users/me/Projects/bayesite/target/release/bayesite
run-sim/simulated_data.json  # format: bayescycle.data.json.v1

The recovery/sample stage can then use jaxstanv5 through its adapter without reading Bayesite-native JSON:

uv run bayescycle sample model.py \
  --data run-sim/simulated_data.json \
  -o run-recover-fit/ \
  --backend jaxstanv5 \
  --seed 2 --chains 4 --warmup 400 --draws 500

The jaxstanv5 adapter materializes the canonical data document as the plain mapping expected by model.bind(...).

Partial plans fail before writes

uv run bayescycle workflow-plan --simulate-backend bayesite

Failure:

Partial backend assignment would create an implicit workflow plan.

simulate: bayesite
recover: inherited from default

Either use --backend for all stages, or provide an explicit complete mixed-backend plan.

Backend-specific options do not select backends

uv run bayescycle workflow-plan --backend jaxstanv5 --engine /path/to/bayesite

Failure: --engine configures Bayesite, but no Bayesite stage was selected. Use --backend bayesite or an explicit mixed plan with a Bayesite stage.
