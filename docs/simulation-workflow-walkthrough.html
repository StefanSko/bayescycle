bayescycle v0 run-directory contract

Simulation-gate workflow commands

This walkthrough shows the first-class command surface added for prior predictive checks, fake-data simulation, recovery, SBC, posterior checks, and recovery checks. Bayescycle owns the paths; Bayesite or jaxstanv5 owns the statistical work.

Run-directory contract

Fresh model-level runs
model.ir.json
data.json
prior_predictive.ndjson
simulated_data.json
recovery.json
sbc.json
Existing posterior run follow-ups
posterior.ndjson → diagnostics.json
posterior.ndjson → posterior_predictive.ndjson
posterior.ndjson → posterior_check.json
posterior.ndjson → recovery_check.json

All commands reserve the engine --out flag so stale artifacts can be cleared and outputs land at standard paths.

1. Prior predictive

bayescycle prior-predictive models/model.py \
  --data data/inputs.json \
  -o runs/prior-0001 \
  --seed 123 --draws 500

Writes runs/prior-0001/prior_predictive.ndjson. The in-process profile can serve this command too:

bayescycle prior-predictive models/model.py \
  --data data/inputs.json \
  -o runs/prior-0001-inproc \
  --backend jaxstanv5 \
  --seed 123 --draws 500

2. Simulate fake data from supplied truth

bayescycle simulate models/model.py \
  --data data/fixed-inputs.json \
  --truth data/truth.json \
  -o runs/sim-0001 \
  --seed 1

Writes runs/sim-0001/simulated_data.json. That data file is an ordinary sample input:

bayescycle sample models/model.py \
  --data runs/sim-0001/simulated_data.json \
  -o runs/recover-fit-0001 \
  --seed 2 --chains 4 --warmup 1000 --draws 1000

3. Recovery check for a fitted fake-data run

bayescycle recover-check runs/recover-fit-0001 \
  --truth data/truth.json \
  --targets data/recovery-targets.json \
  --interval 0.8

Writes runs/recover-fit-0001/recovery_check.json, a factual fit-vs-truth report. It does not invent a pass/fail verdict.

4. Engine-level recovery and SBC reports

bayescycle recover models/model.py \
  --scenario scenarios/recover.json \
  -o runs/recover-0001

bayescycle sbc models/model.py \
  --scenario scenarios/sbc.json \
  -o runs/sbc-0001 \
  --replicates 100

These write recovery.json and sbc.json. Both are factual v0-provisional reports; interpretation belongs to the study gate.

5. Posterior check for a real fit

bayescycle posterior-check runs/fit-0001 --seed 456

Writes runs/fit-0001/posterior_check.json after validating the run directory contains model.ir.json, data.json, and posterior.ndjson.
